Getting started

  1. Create an account and start a family.
  2. Add your athletes and their teams under Teams.
  3. Paste each team’s calendar link (from TeamSnap, SportsEngine, LeagueApps, GameChanger and others) to import its schedule.
  4. Share your invite code from Family so co-parents and carpool partners can join.

Common questions

My team calendar won’t import. Make sure the link is the calendar’s subscribe or iCal link (it usually ends in .ics or starts with webcal://), not the web page you view the schedule on. Then press Sync now on the team.

A game changed but SIDLNE shows the old time. Press Sync now on the team to pull the latest schedule.

I forgot my password. Use “Forgot password?” on the sign-in screen to get a reset link by email.

How do I remove someone from my family? Owners and admins can remove members under Family → Members. Reset the invite code too, so the old one stops working.

Contact us

Report a problem or request a feature on GitHub Issues. Please don’t include private family details in public issues.
